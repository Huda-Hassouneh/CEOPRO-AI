### Provider contract checked against current official documentation

- The current recommended WooCommerce REST API is `/wp-json/wc/v3/`. HTTPS Basic Auth sends the consumer key and secret as username/password; key permissions derive from the associated WordPress user's capabilities. KEEL requires HTTPS and never falls back to query-string secrets. Sources: [REST API v3](https://developer.woocommerce.com/docs/apis/rest-api/v3/) and [Authentication](https://developer.woocommerce.com/docs/apis/rest-api/authentication).
- List endpoints default to 10 items and support 1-based `page` and `per_page`; official docs describe `Link`, `X-WP-Total`, and `X-WP-TotalPages`. The adapter follows the documented next link or total-page header, falls back to another page after a full page if totals are absent, and rejects repeated URLs/content and configured page/response bounds. Source: [REST API pagination](https://developer.woocommerce.com/docs/apis/rest-api/).
- Products and orders use REST v3. Variable products list variation IDs and variations use `/products/{product_id}/variations`; the adapter returns separate provider-scoped product and variation records, retaining the parent ID. Orders are returned as raw provider payloads; status/refund policy is not normalized. Sources: [Products](https://developer.woocommerce.com/docs/apis/rest-api/v3/products), [Product Variations](https://developer.woocommerce.com/docs/apis/rest-api/v3/product-variations/), [Orders](https://developer.woocommerce.com/docs/apis/rest-api/v3/orders/).
- WooCommerce webhook signatures are base64 HMAC-SHA256 over the raw payload in `X-WC-Webhook-Signature`; delivery metadata includes webhook and delivery IDs. The docs state unsuccessful deliveries are retried and the webhook is disabled after five consecutive failures by default. This batch implements only the constant-time signature helper: no HTTP receiver, durable replay record, source attribution or delivery acknowledgment. Source: [Webhooks](https://developer.woocommerce.com/docs/apis/rest-api/v3/webhooks/).
- Core product docs expose stock fields, but do not establish a universal store-location contract. This adapter does not map inventory or location data. No official contract from the checked sources was used to invent an endpoint, API scope, status/refund policy, rate limit, or provider checkpoint.
