Python implements the active owner/admin split with explicit ordinary/exceptional permissions. No Node module, AI subtree, SQL, frontend or dependency was modified or executed as an authority.

Python `routers/auth.py`, `core/security.py`, existing bcrypt/users/auth_tokens, `db.auth_lookup_connection`, `db.app_role_connection`, billing/store.py trials, `usage` seat/accounting and existing tenant role/settings contracts remain the implementation authority. There is no second refresh issuer, Stripe integration, subscription/entitlement ledger, credit counter or canonical company/user store.
