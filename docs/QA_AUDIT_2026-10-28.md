## 4. AI features

### Environment limits (not code)
- **Groq:** the key this environment injects is rejected (`401 Invalid API Key`); it needs rotating.
- **Hugging Face:** the injected token is expired (`whoami`: "User Access Token ... is expired"), so every
  model download (embeddings, re-ranker, sentiment) fails with 401, even for public models.
- **Docker Hub** worked once its anonymous pull limit reset; that is how the local model was obtained.

### Assistant (RAG)
| Test | Result |
|---|---|
| No model available (evidence mode), English and Arabic | PASS - labelled "unsummarised", cites company records and documents |
| Question about another company ("revenue of Beit Al Shawarma") | PASS - only the signed-in company's records appear |
| Off-topic question | FIXED (bug 4) |
| Through the fallback chain `LLM_PROVIDERS=groq,local` (Groq rejected -> local Qwen3-4B) | PASS - revenue answer correct (22,816.48 vs 19,610.56 JOD, +16.3%), cited; 399 s |
| Arabic question about an English document, no embedding model | Wrong but honest ("no information"): cross-language matching needs the multilingual embedding model, which could not be downloaded here |

### Demand forecasting (fully local)
| Case | Result |
|---|---|
| No sales | UNKNOWN with an explanation |
| 13 days of sales | Baseline, confidence 0.2, "BUILDING" |
| Sparse, irregular 6 months | Baseline; range FIXED (bug 3) |
| Steady 120 days | 145 forecast vs 4.8/day actual; restock advice "runs out" with stock 50 |
| Leakage review | None: lags and rolling means use `shift`; backtests predict day *i* from days before *i* |

### Sentiment
Model download blocked (expired token), so the star-rating fallback ran: 1,195 seeded reviews labelled
`star-rating-v1`, and the product page says the basis is the star rating. Upgrade path FIXED (bug 2). The text
model itself could not be run here.

### Marketing
Validation (input source, strategy, platform, CUSTOM theme) returns precise 422s. Without a model: honest 502,
campaign saved as Failed, no fake copy. With the local model: Instagram + Google Ads campaign in 177 s, price
matches the product (12.5 JOD), Google Ads headline 28/30 and description 76/90 characters. Image: no image
provider reachable, so the built-in designed poster was produced and labelled `designed`.

## 5. Security and data integrity checks
- Cross-company access: 23 requests from one company against another's product, competitor, campaign, document,
  chat session and pricing IDs (read, update, delete, forecast, sale) - all 404, nothing changed.
- Uploads: spoofed PDF, HTML, empty, binary and 12 MB files rejected with clear messages; a path-like file name
  is display text only.
- CSV exports (server and browser) neutralise formula cells.

## 6. Cost of the AI features

| Component | Today | Free option and what it costs | Verified here |
|---|---|---|---|
| Assistant and campaign writing | Groq `openai/gpt-oss-20b` | Groq free tier (third-party sources: about 30 requests/min, 1,000/day, 8K tokens/min, no card - not confirmed against Groq's own page, which this sandbox cannot reach). Zero-API-cost fallback: `LLM_PROVIDERS=groq,local` with Qwen3-4B (Apache-2.0) on llama.cpp | Local path works end to end. On this 16-vCPU VM: prompt ~43 tokens/s, answer ~2.5 tokens/s, ~6.8 GB RAM; an assistant turn took 3-7 minutes. Usable as a background or last-resort fallback, not interactive, on CPU; a GPU or Groq's free tier is needed for chat-speed answers. A 4B model also makes factual slips in Arabic small talk, so keep answers grounded in evidence as now |
| Embeddings, re-ranking | Local sentence-transformers / ONNX / static | Already free (open models, run in-process) | Blocked: download needs a valid Hugging Face token |
| Sentiment | Local XLM-RoBERTa | Already free; star-rating fallback | Fallback only |
| Forecasting | Local XGBoost + baselines | Already free | Yes |
| Images | Hosted free tiers, self-hosted SDXL, designed poster | Designed poster is free and always available; SDXL self-hosted is free per image (machine cost) | Designed poster only |

Free software is not free hosting: the local model needs a machine with about 7 GB of RAM to spare (more than the
512 MB staging plan) and gives slow answers on CPU.

## 7. Not tested here
Stripe checkout, SMTP delivery, Google Places / Apify / web search, YouTube comments, the real sentiment and
embedding models, AI image providers and the self-hosted image server - each needs a key, a valid token or a
host this sandbox cannot reach. Destructive actions (company deletion, sign out of all sessions) were not
clicked in the browser.

## 8. How to reproduce
```bash
./keel setup && ./keel start          # or the manual steps in RUNNING_LOCALLY.md
./keel seed                           # demo companies; they now open on the dashboard
./keel test                           # backend + frontend suites
cd frontend && E2E_EMAIL=... E2E_PASSWORD=... node tests/browser/smoke.mjs
# Free local model as the fallback writer:
backend/scripts/fetch_llm_model.sh ./models
pip install "llama-cpp-python[server]"
python -m llama_cpp.server --model models/qwen3-4b-instruct-2507-q4_k_m.gguf --port 8090 --n_ctx 8192
# backend/.env: LOCAL_LLM_BASE_URL=http://localhost:8090/v1/chat/completions  LLM_PROVIDERS=groq,local
#               LOCAL_LLM_TIMEOUT_SECONDS=600 (CPU)   and record a $0 price for provider "local":
#   python -m scripts.billing_admin set-price --budget ai --provider local --operation openai/gpt-oss-20b \
#     --unit input_token --usd-per-million 0 ...   (and --unit output_token)
```
