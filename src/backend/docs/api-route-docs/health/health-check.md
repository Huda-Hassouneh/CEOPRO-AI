# Health Check

## 1. Endpoint Details

`GET /`

## 2. Mental Model

A lightweight liveness endpoint proving the Express application is reachable. It does not inspect the database, Stripe, authentication, or tenant state.

## 3. Technical Decisions

The route is registered after module routers and uses no authentication or JSON body parser dependency beyond the app-level parser. It returns a stable literal message suitable for a basic process check.

## 4. Inputs

- Headers: none required.
- Path/query/body: none.

## 5. Outputs

### Success

`200 OK`

```json
{ "message": "CEO PRO API is running..." }
```

### Errors

No route-specific errors are generated by the handler. Normal Express/server errors may still apply.
